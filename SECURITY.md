# Security policy

falconer-relay has no code yet. Design problems (for example in the README's security requirements) are still
welcome: report them privately through
**[Report a vulnerability](https://github.com/lesquel/falconer-relay/security/advisories/new)**, not as a public
issue.

The overall threat model is in the [umbrella SECURITY.md](https://github.com/lesquel/falconer/blob/main/SECURITY.md).
