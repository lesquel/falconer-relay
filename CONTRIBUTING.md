# Contributing to falconer-relay

This repository is a planned iOS push relay for [Falconer](https://github.com/lesquel/falconer); no
implementation has started. The most useful contributions now are design feedback on the
[README](./README.md) (especially "Security requirements before implementation") and
[ARCHITECTURE.md](./ARCHITECTURE.md).

- Open issues and pull requests in [lesquel/falconer-relay](https://github.com/lesquel/falconer-relay).
- Please open an issue to agree on the approach before writing code.
- When code exists, it follows the same rules as `falconer-hook`: Rust, Clean Architecture by feature,
  `cargo test` green, Conventional Commits.
- How the repositories fit together: [umbrella CONTRIBUTING](https://github.com/lesquel/falconer/blob/main/CONTRIBUTING.md).

Security problems: see [SECURITY.md](./SECURITY.md). By participating you agree to the
[Code of Conduct](https://github.com/lesquel/falconer/blob/main/CODE_OF_CONDUCT.md).
